위닝 펠로우십
3기 지원서

해보고 싶은 일을 나만의 도전으로 현실에서 직접 해 보고, 동료와 나에게 맞는 다음 한 걸음을 정하는 3개월 본과정 지원서입니다. 20살 이상 성인이면 대학 여부와 관계없이 지원할 수 있습니다. 먼저 2주 사전과정에서 직접 해 본 뒤 본과정 합류를 함께 결정합니다.

APPLICATION · 01WINNING FELLOWSHIP 3

지원 상태

  1. 작성
  2. 접수 완료
  3. 2주 사전과정 안내
  4. 본과정 합류 결정

제출은 접수 확인이며 본과정 합류를 뜻하지 않습니다. 안내 대상자에게만 다음 과정을 안내합니다.

작성 전 준비할 내용

  1. 연락받을 휴대전화 번호와 현재 상태
  2. 지금 해보고 싶은 일과, 2주 안에 할 첫 행동
  3. 보고 싶은 현실 반응과 그 반응 뒤 바꿔 볼 다음 선택
  4. 3개월 동안 시간을 낼 계획

이 페이지는 자동 저장되지 않습니다. 제출 전에는 입력한 답변을 다시 읽어보고, 지원서 제출하기를 누르면 접수가 진행됩니다.

입력 내용을 확인해주세요.

    1. 지원자 정보

    만 나이가 아니라 평소 쓰는 나이로 적어주세요. 20살 이상 성인이라면 현재 대학에 다니지 않아도 지원할 수 있습니다.

    사전 선발과정 참여 안내를 받을 번호를 공백·하이픈 없이 입력해주세요.

    2. 지금 해보고 싶은 일

    과거 성과나 자기소개보다, 지금 실제로 해보고 싶은 일을 적어주세요.

    3. 첫 행동과 현실 반응

    완성된 계획은 필요하지 않습니다. 실제 행동과 현실 반응을 적어주세요. 계정 비밀번호나 인증번호, 카드 정보는 적지 말아주세요.

    4. 3개월 현실 참여 계획

    본과정 공식 모임은 격주 90분입니다. 실제로 낼 수 있는 시간과 충돌 대응 방법을 솔직하게 적어주세요.

    참여 가능한 시간대 두 개 이상 *

    실제로 참여할 수 있는 시간대를 두 개 이상 선택해주세요.

    제출 정보는 지원 검토와 다음 과정 안내에만 사용됩니다. 개인정보 안내를 확인해주세요.
